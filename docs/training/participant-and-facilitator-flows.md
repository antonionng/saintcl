# Participant and Facilitator Flows

## Route Structure

- `/training`
- `/training/[programmeSlug]`
- `/training/[programmeSlug]/[moduleSlug]`
- `/training/[programmeSlug]/[moduleSlug]/lab/[labSlug]`
- `/training/admin`

## Participant Flow

1. Open the cohort-linked module route
2. Identify as a named participant
3. Enter the module hub
4. Launch browser labs from the module route
5. Resume progress on return
6. Submit artifacts and complete the module

## Facilitator Flow

1. Create or update programme and cohort structures
2. Inspect module readiness and asset completeness
3. Track attendance and participant progress
4. Monitor runtime health for labs
5. Review submissions and completion evidence
