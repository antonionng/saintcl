# Training Content Model

## Purpose

Standardise how AJB modules are authored so every course can support a participant-first deck of about 80 slides plus labs, downloads, workbooks, and facilitator materials.

## Required Content Blocks Per Module

- programme metadata
- module metadata
- deck target of about 80 participant-facing slides
- content sections with ordered slide allocation
- lab definitions with deliverables and success signals
- datasets and notebooks
- participant workbook
- facilitator guide
- solution files
- rubric items and scoring bands

## Standard Slide Allocation

- launch and orientation: 8 slides
- core concepts: 18 slides
- guided walkthroughs: 16 slides
- hands-on labs: 16 slides
- case discussion and critique: 8 slides
- applied mission or mini-project: 8 slides
- recap, rubric, and next steps: 6 slides

This totals 80 slides.

## Lab Metadata

Each lab should define:
- slug
- title
- deliverable
- success signal
- runtime profile
- expected artifact type

## Asset Pack

Every module should include:
- participant slide deck
- participant workbook
- facilitator guide
- browser lab configuration
- datasets and notebooks
- solution files

## Progress Hooks

Progress should be trackable at:
- check-in
- slide completion
- lab launch
- lab completion
- assessment submission
- module completion
