# AJB Training Portal Rollout Sequence

## Objective

Launch one reusable AJB academy platform for all seven modules, while prioritising the first three modules that have the earliest content and sign-off deadlines.

## Platform Phases

### Phase 1. Foundation

Build once:
- training schema
- protected routes
- programme and module catalogue
- facilitator views
- browser lab runtime abstraction
- participant progress model

## Content Standard Per Module

Every module should ship with:
- about 80 participant-facing slides
- browser labs and tracked execution
- workbook and facilitator guide
- datasets or case materials
- solution files
- progress and completion reporting

## Delivery Logic

- Build the platform once for seven modules
- Productise Python for Data first
- Use the same content and route model for Machine Learning Training
- Reuse the same runtime shell with a stronger compute profile for Neural Networks
- Extend the same patterns to the remaining four modules

## Success Criteria

- No module requires a new product architecture
- Facilitators can manage cohorts from one control room
- Participants can resume progress across modules
- Runtime differences are handled by configuration, not route redesign
