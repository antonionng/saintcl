# Neural Networks Training Pack

This folder contains the current Neural Networks training pack for AJB delivery inside Saint.

## Contents
- `index.html`: participant-facing neural networks deck
- `facilitator-guide.md`: facilitation stance, pacing priorities, and top tips
- `participant-workbook.md`: lab prompts, evidence expectations, and reflection questions
- `notebooks/`: day-by-day working notebooks plus a solution notebook
- `data/`: sample datasets for training-run review and document classification discussion

## Open the Deck

In the app, use:

- `/neural-networks`

## Notes
- The deck reuses the shared training deck assets already serving the Python and Machine Learning modules.
- The structure follows the same full-screen participant deck system used across the AJB academy.
- This pack now includes notebooks, datasets, and a solution path that can be linked directly from the participant academy and facilitator console.
