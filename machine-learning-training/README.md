# Machine Learning Training Pack

This folder contains the current Machine Learning training pack for AJB delivery inside Saint.

## Contents
- `index.html`: participant-facing machine learning deck
- `facilitator-guide.md`: delivery stance, pacing priorities, and top tips
- `participant-workbook.md`: lab prompts, evidence expectations, and reflection questions
- `notebooks/`: day-by-day working notebooks plus a solution notebook
- `data/`: sample datasets for baseline modelling, segmentation, and governance discussion

## Open the Deck

In the app, use:

- `/machine-learning-training`

## Notes
- The deck reuses the shared training deck assets already serving the Python module.
- The structure follows the same premium full-screen teaching format used across the AJB training experience.
- This pack now includes notebooks, datasets, and a solution path that can be linked directly from the academy and facilitator views.
